# WebhookProcessor

WebhookProcessor is a tool that listens for webhooks and sends SMS notifications based on incoming events.

## Production Service Context

- **Base URL**: [https://hook2sms.onrender.com](https://hook2sms.onrender.com)
- **Webhook Endpoint**: `https://hook2sms.onrender.com/webhook`
- **Healthcheck Endpoint**: `https://hook2sms.onrender.com/health`
